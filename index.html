Personal Webpage

Hi, I’m Tingnixi.

這是一個以 GitHub Pages 搭建的個人首頁，透過簡潔暮光色調展示我在 CS351/IN321 AI-assisted Software Development 課程中的學習歷程、技術掌握與設計思考。

Site Overview

這個網站的目標是把課程中的關鍵經驗濃縮成一頁式展示，讓讀者可以快速理解我的技術堆疊、設計理念與學習心得。

  • 技術運用與實作重點
  • 設計概念與視覺風格
  • 個人反思與課程總結

頁面結構維持簡潔、資訊清楚，同時兼顧深色主題的質感與可讀性，適合 GitHub Pages 的靜態部署。

Technologies used

我在這個專案中實際應用或深入理解的技術，涵蓋前端、部署與團隊協作三大面向：

  • HTML5 / CSS3 - 建立語意化結構與現代化深色介面
  • GitHub Pages - 使用 GitHub 的靜態網站服務進行快速部署
  • Responsive design - 透過彈性排版確保手機與桌機環境都有良好體驗
  • AI-assisted development - 將 AI 工具納入內容生成與文案優化流程
  • 版本控制與協作流程 - 練習 Git 分支、提交與合併策略
  • Jira Story / 任務管理 - 透過 Story 與任務分配管理開發進度與需求

Design concept

本網站以深色配色為核心，結合簡潔卡片式布局，強調資訊層次與視覺節奏：

  • 深色背景搭配冷色高光，營造科技感與穩重氛圍
  • 卡片區塊與明確間距，讓內容段落更容易閱讀與吸收
  • 響應式網格設計，確保不同螢幕尺寸下資訊呈現一致
  • 標題與重點文字使用明亮色調，引導閱讀焦點

Personal reflection

這堂課讓我重新審視 AI 與軟體開發結合的實際價值，從工具使用到團隊協作，每一步都強化了我的系統思維。

我認為最重要的收穫在於：

  • 理解如何用 Git 管理版本、協調多人開發與變更歷史
  • 體會 Jira 任務拆解與分配對專案進度管理的關鍵作用
  • 學會將 AI 輔助流程融入需求分析、內容產出與迭代修正
  • 建立更清晰的設計思維，讓技術實作與使用者體驗相互補強

未來我希望持續提升專案溝通、問題追蹤與自動化部署能力，讓每一次開發都更有紀律、更能快速回應需求變化。

Course summary

CS351/IN321 的課程內容涵蓋 AI-assisted development 的實務應用，並強調負責任的技術實踐與團隊合作。

  • AI 助手在需求理解、程式生成與除錯中的實際角色
  • 以敏捷流程管理軟體生命週期與團隊協作
  • 測試、版本控制與 CI/CD 概念的整合應用
  • AI 使用中的倫理考量、資料安全與可解釋性

這是為 CS351/IN321 課程準備的 GitHub Pages 個人作品頁，展示我對技術與設計的思考。
