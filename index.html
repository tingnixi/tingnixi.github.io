Personal Webpage

Hi, I’m Tingnixi.

這是一個以 GitHub Pages 建置的個人首頁，展示我在 CS351/IN321 AI-assisted Software Development 課程中的技術應用、設計概念與學習反思。

Site Overview

這個網站主要用來呈現課程成果與個人學習心得。內容分成：

  • Technologies used
  • Design concept
  • Personal reflection

所有內容皆放在單一頁面中，並使用簡潔的深色主題與響應式排版，適合 GitHub Pages 部署。

Technologies used

我在這個網頁與課程中使用或理解的技術包括：

  • HTML5 / CSS3 - 建構語意化網頁與樣式設計
  • GitHub Pages - 將靜態網站部署到 GitHub
  • Responsive design - 支援手機與桌機瀏覽
  • AI-assisted development - 結合 AI 工具來輔助開發與學習
  • 版本控制與協作流程 - 使用 Git 進行團隊合作
  • Jira Story / 任務管理 - 規劃與分配開發任務

Design concept

網站採用深色風格，強調內容可讀性與簡潔結構：

  • 深色背景搭配冷色強調色，維持現代感與專業感
  • 卡片式區塊與留白讓內容更容易閱讀
  • 使用響應式網格排版，確保小螢幕上也能清楚呈現
  • 以清晰標題與段落呈現課程關鍵資訊

Personal reflection

我在這堂課學到了在多個人共同開發的環境下，我們要如何使用 git 來共同協作、控制版本，以及使用 Jira 這個平台來建立 Story 等等，用於發配給不同成員任務。

這其中最有價值的是：

  • 理解團隊協作與版本控制的流程
  • 體會任務拆解與工作分派的重要性
  • 將 AI 工具整合進開發流程，提升效率與品質

未來我會繼續加強實際專案中的「協作溝通」、「問題追蹤」與「持續部署」能力，讓產品開發流程更加完整。

Course summary

CS351/IN321 這門課的重點包含：

  • AI-assisted 開發工具在軟體生命週期中的應用
  • 透過 AI 支援進行需求理解、程式生成與除錯
  • 敏捷協作、測試與 CI/CD 的實踐概念
  • 負責任使用 AI 的倫理與資料安全議題
